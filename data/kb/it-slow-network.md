# Troubleshooting Slow Internet and Network

This article provides guidance on troubleshooting slow internet and network connections both at home and in the office. It outlines steps for diagnosing issues, performing speed checks, and understanding the differences between Wi-Fi and wired connections, as well as when to escalate the problem to IT support.

## Diagnosing Slow Internet Connections

To diagnose slow internet connections, follow these steps:

1. **Check Other Devices**: Determine if the slow connection is isolated to one device or affects multiple devices. If other devices are also slow, the issue may be with the network itself.
2. **Restart Devices**: Restart your computer and router. This can resolve many connectivity issues.
3. **Check Network Configuration**: Ensure that your network settings are correct. For company devices, refer to the network configuration guide in PeopleHub or consult with IT.
4. **Run Diagnostic Tools**: Use built-in network diagnostic tools on your device to identify potential issues. For Windows, you can run the Network Troubleshooter; for Mac, use the Wireless Diagnostics tool.
5. **Check for Bandwidth-Heavy Applications**: Close any applications that may be using significant bandwidth (e.g., video streaming, large downloads).
6. **Test Connection Speed**: Use an online speed test tool (like Ookla Speedtest) to check your internet speed. Compare the results with your expected speeds based on your internet plan.

## Wi-Fi vs Wired Connections

When troubleshooting, consider the type of connection:

- **Wi-Fi**: 
  - Ensure you are connected to the correct SSID ("NovaTech-Corp"). 
  - Check the signal strength; if weak, try moving closer to the router or access point.
  - Interference from other devices (microwaves, cordless phones) can affect Wi-Fi performance.

- **Wired**: 
  - Ensure the Ethernet cable is securely connected to both the device and the router.
  - Check for any visible damage to the cable.
  - If possible, test with a different Ethernet cable to rule out cable issues.

## When to Raise an Incident

If the above steps do not resolve the issue, or if you identify that the problem is network-wide (affecting multiple users), it may be necessary to raise an incident. Here are some scenarios:

1. **Persistent Issues**: If you continue to experience slow internet despite following troubleshooting steps.
2. **Network-Wide Problems**: If multiple users report similar issues, indicating a potential network failure.
3. **Hardware Issues**: If you suspect a hardware issue (e.g., network interface card) that requires physical inspection or replacement.
4. **Configuration Adjustments**: If you believe that network settings need to be adjusted by IT.

To raise an incident, please submit a request through ServiceHub or contact the IT Service Desk at ext. 2020.

## Frequently asked questions

### What should I do if my internet is slow at home?

Follow these steps:
1. Restart your router and device.
2. Check if other devices are also slow.
3. Run a speed test to measure your connection.
4. Close any bandwidth-heavy applications.
5. If the issue persists, contact your internet service provider.

### How can I check my internet speed?

You can check your internet speed using an online tool like Ookla Speedtest. Simply visit the website, click 'Go', and wait for the test to complete.

### Is it better to use Wi-Fi or a wired connection for work?

A wired connection is generally more stable and faster than Wi-Fi. If you experience slow internet, try using an Ethernet cable to connect directly to the router.

### When should I contact IT support for slow internet issues?

Contact IT support if:
- You have followed all troubleshooting steps and the issue persists.
- Multiple users are experiencing slow internet.
- You suspect a hardware issue that requires inspection.
