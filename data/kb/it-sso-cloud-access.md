# Single Sign-On and Cloud App Access

This article provides guidance on accessing cloud tools via the Okta dashboard, requesting new app tiles, troubleshooting 'not assigned' errors, and managing onboarding and offboarding access for employees at NovaTech Solutions.

## Accessing Cloud Tools via the Okta Dashboard

To access your cloud applications using the Okta dashboard, follow these steps:

1. Open your web browser and navigate to the Okta login page.
2. Enter your Okta credentials (username and password) and complete the multi-factor authentication (MFA) process using Okta Verify.
3. Once logged in, you will see the dashboard with tiles for all the applications you have access to.
4. Click on the tile of the application you wish to access, and it will redirect you to the application without needing to log in again.

## Requesting a New App Tile

If you need access to a cloud application that is not listed on your Okta dashboard, you can request a new app tile by following these steps:

1. Log in to ServiceHub (https://servicehub.novatech.example).
2. Navigate to the IT Support section.
3. Select "Request New Application" from the options.
4. Fill out the request form with the necessary details, including the name of the application and the reason for access.
5. Submit the request. The IT team will review it and notify you once the app tile is added.

## Troubleshooting 'Not Assigned' Errors

If you encounter a 'not assigned' error when trying to access a cloud application, follow these steps:

1. Verify that you are logged into the Okta dashboard.
2. Check if the application tile is visible on your dashboard.
3. If the tile is present but you still receive the error, contact the IT Service Desk via ServiceHub or email itsupport@novatech.example.
4. Provide details about the error message and the application you are trying to access so the team can assist you promptly.

## Onboarding and Offboarding Access

To ensure smooth onboarding and offboarding access for employees, please adhere to the following guidelines:

**Onboarding Access:**
1. New hires should be added to the relevant applications as part of the onboarding process.
2. HR must inform the IT department of new hires at least 10 working days before their start date.
3. IT will provision access to necessary applications, including any department-specific tools, as indicated by the hiring manager.

**Offboarding Access:**
1. When an employee leaves the company, HR must notify IT immediately.
2. IT will revoke access to all cloud applications and services associated with the employee's account on their last working day.
3. Ensure that any necessary data is backed up or transferred before access is revoked.

## Frequently asked questions

### What should I do if I can't find a specific cloud application in Okta?

If you can't find a specific cloud application in Okta, you can request a new app tile through ServiceHub. Navigate to the IT Support section and select 'Request New Application' to submit your request.

### How do I troubleshoot access issues with cloud applications?

If you experience access issues, first check if the application tile is visible in your Okta dashboard. If you see a 'not assigned' error, contact the IT Service Desk for assistance.

### What is the process for onboarding new employees with cloud app access?

HR must notify IT of new hires at least 10 working days before their start date. IT will provision access to necessary applications based on the roles and department requirements.

### How is access managed for employees who leave the company?

When an employee leaves, HR must inform IT immediately. IT will revoke access to all applications on the employee's last working day.

### What should I do if I experience authentication failures with a cloud application?

If you experience authentication failures, ensure you are using the correct credentials and have completed the MFA process. If issues persist, contact the IT Service Desk for further assistance.
