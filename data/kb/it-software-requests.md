# Software Installation and Licence Requests

This article provides guidance on installing pre-approved applications from the Software Center and Self Service, as well as the process for requesting new software or paid licenses through ServiceHub. It outlines the approval process and expected lead times for software requests.

## Installing Pre-Approved Applications

Employees can install pre-approved applications directly from the Software Center (Windows) or Self Service (macOS). Follow these steps:

1. **Access the Software Center or Self Service:**  
   - For Windows, open the **Software Center** from the Start menu.  
   - For macOS, open **Self Service** from the Applications folder.

2. **Browse Available Applications:**  
   - In the Software Center or Self Service, browse through the list of available applications.

3. **Select the Application:**  
   - Click on the application you wish to install.

4. **Install the Application:**  
   - Click the **Install** button and follow any on-screen prompts to complete the installation.

5. **Verify Installation:**  
   - Once installed, check that the application is functioning properly by launching it from your applications list.

## Requesting New Software or Paid Licenses

If the software you need is not available in the Software Center or Self Service, you can request it through ServiceHub. Here’s how to do it:

1. **Log in to ServiceHub:**  
   - Go to [ServiceHub](https://servicehub.novatech.example) and log in with your Okta credentials.

2. **Navigate to Software Requests:**  
   - Click on the **IT Support** category.
   - Select **Software Requests** from the options available.

3. **Fill Out the Request Form:**  
   - Provide details such as the software name, required version, and a brief justification for the request.
   - If applicable, specify whether you need a paid license.

4. **Submit the Request:**  
   - Review your information and click **Submit** to send your request to the IT team.

5. **Await Approval:**  
   - Your request will be reviewed by the IT team. You will receive a notification regarding the approval status.

6. **Installation:**  
   - Once approved, IT will either install the software for you or provide further instructions.

## Approval Process and Lead Times

The approval process for new software requests typically involves the following:

1. **Review by IT:**  
   - IT will assess the request based on company policy, software compatibility, and budget considerations.

2. **Approval Notification:**  
   - You will receive an email notification regarding the approval or denial of your request.

3. **Lead Times:**  
   - Approval times can vary, but generally, you can expect a response within 3-5 business days. If the software requires additional budget approval, it may take longer.

## Frequently asked questions

### How do I install software from the Software Center or Self Service?

To install software, open the Software Center (Windows) or Self Service (macOS), browse available applications, select the desired application, and click the Install button.

### What should I do if the software I need is not listed in the Software Center or Self Service?

If the software is not available, you can request it through ServiceHub by filling out the IT Support > Software Requests form.

### How long does it take to get approval for new software requests?

Approval for new software requests typically takes 3-5 business days, depending on the complexity of the request and budget considerations.

### Can I request a paid license for software through ServiceHub?

Yes, when filling out the software request form in ServiceHub, you can specify if you need a paid license for the software.

### What happens if my software request is denied?

If your request is denied, you will receive a notification explaining the reason for the denial. You may have the option to discuss alternatives with the IT team.
